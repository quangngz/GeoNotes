Google Maps Static API → HTML

1) Basic static map (center + zoom + one marker)

URL built from parameters: center, zoom, size, scale, maptype, markers, and key.

2) Multiple markers (URL-encode pipes and spaces)

3) Path/route overlay (polyline)

4) Programmatically build the URL (optional)

Change fields and the image will update.

Need an interactive map instead?

Use the Maps JavaScript API (different product). Minimal drop‑in example: 

<div id="map" style="height:400px"></div>
<script>
  function initMap() {
    new google.maps.Map(document.getElementById('map'), {
      center: { lat: -37.8136, lng: 144.9631 },
      zoom: 13,
    });
  }
</script>
<script src="https://maps.googleapis.com/maps/api/js?key=AIzaSyBBUmA4z0sdQ_iRDGfClwXPZggthxMhhv0
&callback=initMap&v=weekly" async defer></script>
